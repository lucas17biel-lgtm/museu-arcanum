# Museum Arcanum

Site conceitual de museu arqueológico desenvolvido com HTML, CSS e JavaScript puro.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra a pasta `museum-arcanum`.
3. Abra `index.html` no navegador.

Também é possível usar a extensão **Live Server** no VS Code para visualizar o projeto.

## Arquivos
- `index.html` — estrutura e conteúdo das páginas/seções.
- `styles.css` — identidade visual, layout responsivo e animações.
- `script.js` — busca, filtros, modal de artefatos e menu mobile.

## Publicação no Vercel
1. Crie um repositório no GitHub.
2. Envie os três arquivos principais (`index.html`, `styles.css` e `script.js`) e o README.
3. No Vercel, escolha **Add New → Project** e importe o repositório.
4. Como é um site estático, não precisa de build command nem de banco de dados.

## Observações
- As imagens são carregadas de URLs externas do Unsplash; é necessária conexão com a internet para visualizá-las.
- O acervo e o nome do museu são demonstrativos. Revise datas, descrições e direitos de uso das imagens antes de apresentar o site como instituição real.
